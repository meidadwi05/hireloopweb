# HireLoop React — Source Lengkap

Ekspor desain HireLoop B2C terbaru tanggal 2 November 2026. React + Vite, JSX per section, CSS responsif, gambar WebP, logo, font lokal, QR ilustrasi, dan animasi/transisi disertakan.

Paket menggunakan path dari root domain (/assets/, /interactions.js, dan /animations.js).

## Revisi Terbaru

- Wording landing page diperbarui.
- Bagian perusahaan dan halaman B2B dihapus.
- Kolom pencarian, pilihan lokasi, tombol pencarian, dan empat poin di bawah hero dihapus.
- Filter industri dan daftar lowongan dipertahankan.
- Wordmark HireLoop di footer bergerak tanpa anak panah.
